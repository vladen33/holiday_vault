# Правила проекта «Праздники события»

## Главный формат — мобильный телефон

- Вёрстка mobile-first: базовые стили пишутся для узкого экрана, затем
  расширяются через `min-width`-брейкпоинты.
- Десктоп — вторичный формат: он должен быть полным и удобным, но не может
  ухудшать мобильный опыт.
- Никакого горизонтального скролла на ширине 320–390 px.
- Тач-цели — не меньше 44 × 44 px.
- Таблицы, длинные заголовки и код должны переноситься или прокручиваться
  внутри своего блока, а не растягивать страницу.
- Проверять как минимум ширины 360, 390, 768, 1024 и 1440 px.
- Учитывать `prefers-reduced-motion`, видимый фокус и управление с клавиатуры.

## Общие принципы

- Проект статический: HTML, CSS и немного JavaScript, без сборки и внешних
  запросов.
- Все пути относительные — проект работает и по `file://`, и на GitHub Pages.
- Страницы должны оставаться читаемыми без JavaScript; интерактивность —
  прогрессивное улучшение.
