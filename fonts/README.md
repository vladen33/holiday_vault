# Каталог шрифтов

Здесь хранятся локальные шрифты проекта — чтобы все ресурсы лежали внутри
`holiday_vault` и ни один запрос не уходил в интернет.

## Что используется сейчас

Пока проект обходится системным стеком (задан в `css/base.css`):

```css
--font-body: system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif;
```

Он есть на любой ОС, ничего не скачивает и одинаково работает и по `file://`,
и на GitHub Pages. Поэтому каталог пока пуст.

## Важное ограничение `file://`

При открытии страницы двойным кликом по `index.html` Chrome и Chromium-браузеры
блокируют загрузку файлов шрифтов через `@font-face`: политика CORS, origin
`file://` считается «null». На GitHub Pages (http/https) этой проблемы нет.

Поэтому, если понадобится свой шрифт, есть два рабочих пути.

### 1. Встроить шрифт в CSS (base64)

Файл шрифта превращается в строку `data:` URI:

```css
@font-face {
  font-family: "My Font";
  src: url("data:font/woff2;base64,....") format("woff2");
  font-display: swap;
}
```

Плюс: работает и по `file://`, и на Pages. Минус: CSS-файл заметно растёт,
а base64-строка плохо читается и не кэшируется отдельно.

### 2. Обычный файл `.woff2` в этом каталоге

```css
@font-face {
  font-family: "My Font";
  src: url("../fonts/my-font.woff2") format("woff2");
  font-display: swap;
}
```

Плюс: чистый CSS, шрифт кэшируется браузером. Минус: при открытии по `file://`
в Chrome шрифт не загрузится (сработает системный fallback) — нужен локальный
сервер (`python3 -m http.server`) или GitHub Pages.

## Правила для файлов

- Формат — `woff2` (самый компактный, поддерживается всеми актуальными браузерами).
- Имена — строчная латынь без пробелов: `my-font-regular.woff2`,
  `my-font-bold.woff2`.
- Рядом со шрифтом положите файл лицензии (`LICENSE-*.txt`) — шрифты почти
  всегда распространяются по лицензии, требующей указания авторства.
- Подключайте только те начертания, которые реально используются:
  каждое лишнее — это лишние килобайты для офлайн-проекта.
